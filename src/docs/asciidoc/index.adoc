`data.content`의 마지막 항목 `id`를 넘긴다. `cursor`를 생략하면 최신 항목부터 조회한다.

== 클릭 이벤트 목록 조회

`id`(단축 URL의 내부 id) 아래 중첩된 리소스로 조회한다. 페이지네이션 방식은 단축 URL 목록
조회와 동일하다. 존재하지 않는 id로 조회해도 404가 아니라 빈 목록(200)을 반환한다 - 만료된
단축 URL의 클릭 이력도 조회 가능해야 하므로, 리다이렉트처럼 존재/만료 여부를 엄격히 검사하지
않는다.
