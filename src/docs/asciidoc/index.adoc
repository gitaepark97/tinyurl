== 단축 URL 생성

로그인 없이도 생성할 수 있다. `customAlias`/`expiresAt`은 회원 전용이며, 비회원이 값을 채워
보내면 403을 반환한다. `customAlias`는 리다이렉트 라우트와 같은 규칙(1~8자 영숫자)을 따르고,
`expiresAt`은 현재로부터 최대 1개월까지 지정할 수 있다(비회원 및 지정하지 않은 회원은 7일 고정).

`cursor`를 생략하면 최신 항목부터 조회한다.

== 단축 URL 단건 조회

`shortKey`가 아니라 단축 URL의 내부 `id`로 조회한다(목록 조회 응답의 `id`를 그대로 사용). 만료된
단축 URL도 조회 가능하다(리다이렉트만 막히고 조회는 계속 가능해야 하기 때문). 회원이 생성한
URL은 소유자 본인 또는 관리자만 조회할 수 있고(그 외 403), 비회원이 생성한(소유자가 없는) URL은
관리자만 조회할 수 있다.

== 클릭 이벤트 목록 조회

`id`(단축 URL의 내부 id) 아래 중첩된 리소스로 조회한다. 페이지네이션 방식은 단축 URL 목록
조회와 동일하다. 단건 조회와 같은 소유권 규칙을 따른다 - 회원 소유 URL은 소유자 본인 또는
관리자만, 비회원 생성 URL은 관리자만 조회할 수 있다. 존재하지 않는 id로 조회하면 404를
반환한다.
