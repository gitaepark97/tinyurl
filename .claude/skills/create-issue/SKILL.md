# 이슈 생성

`gh issue create`를 사용해 `gitaepark97/tinyurl` 저장소에 이슈를 생성한다.

## 절차

1. 이슈 내용을 파악한다.
   - 사용자의 요청에 이미 충분한 정보(제목 + 설명)가 있다면 그대로 사용하고, 불필요한 질문은 하지 않는다.
   - 핵심 정보(무엇에 대한 이슈인지, 버그/기능 등 종류)가 부족하면 이슈를 만들기 전에 간단히 확인 질문을 한다. 제목과 본문은 자유 형식이며 고정된 템플릿은 없다.
2. 사용자의 설명을 바탕으로 명확하고 간결한 제목과 본문을 한국어로 작성한다(사용자가 영어로 작성한 경우는 예외).
3. 이슈를 생성하기 전에 초안(제목, 본문)을 사용자에게 보여주고 확인받는다 — 이슈 생성은 다른 사람에게도 보이는 작업이므로, 사용자가 이미 정확한 내용을 명시적으로 승인한 경우가 아니라면 반드시 먼저 확인한다.
4. 다음과 같이 생성한다:

```bash
gh issue create --repo gitaepark97/tinyurl --title "<제목>" --body "$(cat <<'EOF'
<본문>
EOF
)"
```

5. `gh issue create`가 반환한 이슈 URL을 사용자에게 알려준다.

## 참고

- `--web` 옵션은 브라우저를 열려고 시도하므로 절대 사용하지 않는다 — 항상 위 CLI 플래그로 바로 생성한다.
- `gh auth status`가 실패하면 직접 로그인을 시도하지 말고 사용자에게 `gh auth login`을 직접 실행하도록 안내한다.
